
# Task 2: Exploratory Data Analysis (EDA)

Dataset: Iris (scikit-learn)

## Objective
- Generate summary statistics
- Create histograms and boxplots
- Analyze correlations
- Identify trends and anomalies

## Observations
- Petal length and petal width are highly correlated.
- Sepal measurements show moderate correlation.
- No significant outliers are present.
- Species are separable using petal features.

## Interview Answers

1. **Purpose of EDA:** Understand data structure, quality, distributions, relationships, and detect issues before modeling.
2. **Boxplots:** Show spread, median, quartiles, and outliers.
3. **Correlation:** Measures linear relationship between variables; useful for feature selection.
4. **Detect skewness:** Histograms, skewness statistic, boxplots, QQ plots.
5. **Multicollinearity:** Highly correlated independent variables causing unstable models.
6. **EDA Tools:** Pandas, Matplotlib, Seaborn, Plotly, NumPy.
7. **Example:** EDA revealed missing values/outliers leading to preprocessing before training.
8. **Visualization Role:** Makes patterns, trends, clusters, and anomalies easy to interpret.
